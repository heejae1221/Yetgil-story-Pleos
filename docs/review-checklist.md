# 이야기 검수표 (시연 장소)

시연 경로(경부고속도로) 6곳 13편: 직접 쓴 이야기 11편 + 통도사·범어사의 국가유산청 원문 2편. 사실·표현을 확인하고, 괜찮으면 해당 편의 `"reviewed": false` 를 `true` 로 바꾼다.
검수된 편만 '아이와 함께' 모드에서 나온다. 고친 뒤 `./gradlew :collector:run --args="validate data/packs/<파일>"` 로 검사.

확인할 것: ① 사실이 출처와 맞는가 ② 전설을 사실처럼 말하지 않는가 ③ 아이가 듣기에 쉬운가 ④ 퀴즈 정답 표현(answers)이 충분한가
